11.01
공부 기록

CSS animation, fade up부터 차근차근

keyframes로 요소가 아래에서 위로 떠오르는 효과를 직접 만들어 봤어요. 코드와 원리를 정리했어요.

더 읽기

fade up은 요소가 투명한 상태로 조금 아래에 있다가, 제자리로 올라오면서 선명해지는 효과예요.

@keyframes에서 시작 상태를 opacity: 0; transform: translateY(20px);로 두고 끝 상태를 opacity: 1; transform: none;으로 잡으면 끝이에요.

animation-delay를 요소마다 조금씩 다르게 주면 카드가 차례대로 올라오는 느낌을 낼 수 있어요. top, margin 대신 transform을 써야 화면이 덜 버벅여요.

11.01
개발 일지

관심사 블로그, HTML/CSS로 직접 만들기

flex, grid, absolute를 나눠 쓰면서 헤더부터 푸터까지 레이아웃을 잡은 과정이에요.

더 읽기

헤더와 메뉴처럼 한 줄로 늘어서는 건 flex, 사진첩처럼 가로세로 칸이 있는 건 grid로 나눴어요.

날짜 배지나 TOP 버튼처럼 다른 요소 위에 떠 있어야 하는 건 position: absolute와 fixed를 썼어요.

마지막으로 media.css에서 768px 이하 화면을 따로 잡아, 모바일에서도 깨지지 않게 다듬었어요.

11.01
개발 일지

API 연동 처음 해보기: 날씨 데이터 가져오기

Fetch로 날씨 API를 호출하고 화면에 보여주는 과정을 단계별로 정리했어요.

더 읽기

날씨 API에 가입해서 키를 받은 다음, fetch(주소)로 데이터를 요청했어요.

응답은 await res.json()으로 객체로 바꾸고, 그 안의 기온과 날씨 상태를 꺼내 화면에 넣었어요.

주소가 틀리거나 인터넷이 끊기면 에러가 나서, try...catch로 감싸 "날씨를 불러오지 못했어요" 같은 안내를 보여주도록 했어요.
